# AI 가챠 게임

플레이어가 만든 세계관으로 스토리와 전투, 소환을 즐기는 웹 AI 게임을 단계적으로 제작하는 프로젝트입니다.

## 현재 구현

- 밝은 페이지 배경과 중앙의 다크 게임 프레임
- 왼쪽 설정 메뉴와 오른쪽 콘텐츠 영역
- 텍스트 생성 AI / 이미지 생성 AI 서브 탭 전환
- 오른쪽의 `+ AI 연결 추가` 버튼 디자인
- CSS 변수로 분리된 테마 색상

현재는 기본 화면만 구현되어 있습니다. AI 연결 입력 폼, 실제 모델 호출, 게임 생성 기능은 아직 구현되지 않았습니다.

## 실행

별도 설치나 빌드 없이 `index.html`을 브라우저에서 열면 됩니다.

## GitHub Pages

저장소의 **Settings → Pages**에서 다음과 같이 선택할 수 있습니다.

- Source: Deploy from a branch
- Branch: main
- Folder: / (root)

현재 소스 업로드 작업에서는 Pages 설정을 변경하지 않았습니다.
