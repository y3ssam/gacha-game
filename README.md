# AI 가챠 게임

플레이어가 만든 세계관으로 스토리와 전투, 소환을 즐기는 웹 AI 게임을 단계적으로 제작하는 프로젝트입니다.

## 현재 구현

- 밝은 페이지 배경과 중앙의 다크 게임 프레임
- 왼쪽 설정 메뉴와 오른쪽 콘텐츠 영역
- 텍스트 생성 AI / 이미지 생성 AI 서브 탭 전환
- 오른쪽의 `+ AI 연결 추가` 버튼과 입력 화면 전환
- 중앙 정렬된 모델 종류 선택 및 API KEY 입력 칸
- 텍스트 모델용 Vertex AI JSON 키 전체 입력 영역
- 텍스트 모델용 이름·리전·모델 입력 칸 및 테스트 메시지 전송 버튼
- 왼쪽 AI 연결 메뉴를 통한 목록 화면 복귀
- CSS 변수로 분리된 테마 색상

현재는 연결 입력 화면을 구현한 단계입니다. 텍스트 모델은 Vertex AI JSON 키 전체를 입력하며, 이미지 모델의 키는 가려서 표시합니다. 키를 저장하거나 전송하지 않습니다. 테스트 메시지 전송 버튼의 실제 API 호출, 모델 연결과 게임 생성 기능은 아직 구현되지 않았습니다.

## 실행

별도 설치나 빌드 없이 `index.html`을 브라우저에서 열면 됩니다.

## GitHub Pages

저장소의 **Settings → Pages**에서 다음과 같이 선택할 수 있습니다.

- Source: Deploy from a branch
- Branch: main
- Folder: / (root)

현재 소스 업로드 작업에서는 Pages 설정을 변경하지 않았습니다.
