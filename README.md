# AI 가챠 게임

플레이어가 만든 세계관으로 스토리와 전투, 소환을 즐기는 웹 AI 게임을 단계적으로 제작하는 프로젝트입니다.

## 현재 구현

- 밝은 바깥 배경과 중앙의 다크 게임 프레임
- 왼쪽 설정 메뉴, 텍스트·이미지 모델 탭, 연결 입력 화면과 뒤로가기
- 텍스트 모델의 Vertex AI 서비스 계정 JSON 키, 이름, 리전, 모델 ID 입력
- JSON 키의 프로젝트 ID와 선택한 리전·모델로 Gemini 요청 주소 자동 구성
- 로컬 서버에서 Google OAuth 인증 후 선택한 모델에 `hello` 전송
- 실제 모델 답변은 연두색 배경·진한 초록색 글자, 오류는 분홍색 배경·빨간 글자로 표시
- 진행 중 중복 전송 방지, 입력 변경·뒤로가기 시 이전 테스트 취소
- 입력 화면 오른쪽 아래 저장 버튼과 저장된 연결 목록·수정
- 이름·리전·모델 ID와 JSON 키를 Windows 계정 암호화(DPAPI)로 PC에 저장
- 저장한 연결을 다시 열어 키를 다시 입력하지 않고 연결 테스트

이미지 모델 연결, 게임 생성, 게임 데이터 저장·내보내기·불러오기는 아직 구현하지 않았습니다. 이름은 연결 목록과 이후 게임 생성 화면에서 사용할 표시 이름이며, Google 인증에 사용하지 않습니다.

## 로컬 실행 (Windows)

1. Node.js 22 이상을 설치합니다.
2. 저장소를 내려받아 압축을 풉니다.
3. `start-local.cmd`를 실행하거나, 해당 폴더의 터미널에서 `npm start`를 실행합니다.
4. 표시된 주소 `http://127.0.0.1:4173`에 접속합니다.
5. 텍스트 생성 AI → AI 연결 추가에서 서비스 계정 JSON 키 전체, 표시 이름, 리전, 실제 모델 ID를 입력합니다.
6. **테스트 메시지 전송**을 누릅니다. 실제 모델 요청이므로 Google Cloud 사용료가 발생할 수 있습니다.

추가 패키지 설치나 빌드가 필요하지 않습니다. 실행 창을 닫거나 Ctrl+C를 누르면 서버가 종료됩니다. 포트가 사용 중이면 기존 서버를 종료하거나 `PORT` 환경 변수로 다른 포트를 지정합니다.

## 인증과 키 처리

- 지원 대상: Google Vertex AI의 Google Gemini `generateContent` API와 `service_account` 형식의 JSON 키.
- Google Cloud 프로젝트의 결제 설정, Vertex AI API 활성화, 서비스 계정의 적절한 Vertex AI 권한이 필요합니다.
- `project_id`는 JSON 키에서 읽습니다. 다른 프로젝트를 지정하는 기능은 아직 없습니다.
- 기본 리전은 `global`입니다. 모델마다 사용할 수 있는 리전이 다릅니다.
- 입력한 JSON 키는 브라우저에서 PC의 로컬 서버로 전달됩니다. 개인 키는 서버 메모리에서 인증 요청 서명에만 사용합니다. Google에는 서명된 인증 요청과 모델 호출을 보냅니다.
- **저장**을 누르면 이름·리전·모델 ID와 JSON 키를 `%LOCALAPPDATA%\\GachaGame\\connections.dpapi`에 Windows 현재 사용자 계정(DPAPI)으로 암호화해 보관합니다. 브라우저 저장소에는 키를 저장하지 않습니다.
- 액세스 토큰은 저장하지 않습니다. 저장된 JSON 키를 서버에서 복호화하여 필요할 때 새 인증을 받습니다. 목록·수정 화면에 개인 키를 반환하지 않습니다.
- 기존 연결을 수정할 때 JSON 칸을 비워두면 저장된 키를 유지하고, 새 JSON을 입력하면 키를 교체합니다. 저장 성공 후 목록으로 돌아가며 입력값은 비웁니다.
- 저장하지 않고 뒤로가면 입력값만 비웁니다. 저장된 연결은 그대로 유지됩니다.
- 암호화 파일은 같은 Windows 사용자 계정에서 사용합니다. 다른 PC로 연결 키를 내보내고 불러오는 기능은 아직 없습니다.
- 저장 버튼은 연결 정보를 저장하며 Google 연결 테스트를 자동 실행하지 않습니다. 저장된 연결이 항상 유효하다는 뜻은 아니므로 필요하면 테스트를 실행하세요.
- 서버는 `127.0.0.1`에만 열리고 다른 웹사이트의 요청을 거절합니다. 인증 대상은 Google OAuth, 모델 호출 대상은 고정된 Google API 호스트로 제한합니다.
- 실제 키 JSON은 저장소에 추가하지 마세요.

인증 실패는 JSON 키의 유효성을, 403 오류는 API·결제·권한을, 404 오류는 모델 ID와 리전을 확인하세요. 429 오류는 요청 한도나 모델 용량에 따라 발생할 수 있습니다. 화면에 Google 오류 내용과 확인할 항목을 함께 표시합니다.

## GitHub Pages

Pages 설정을 변경하지 않았습니다. `main` 브랜치의 `/ (root)`로 화면을 배포할 수 있습니다.

GitHub Pages에서는 화면을 확인할 수 있지만 서버 코드는 실행되지 않습니다. **실제 인증·연결 테스트는 `npm start`로 실행한 로컬 게임 주소에서 사용합니다.** Pages에서 로컬 인증 서버로 키를 보내지는 않습니다.

## 검증

`npm test`로 테스트를 실행합니다. 테스트 전용 RSA 키를 메모리에서 생성하고 Google 응답을 대체해, 서명·요청 주소·hello 전송·오류 처리·로컬 서버의 출처 검사와 Windows 암호화 저장·복원·수정을 검증합니다. 실제 Google 모델 응답을 보장하는 실계정 테스트와는 구분됩니다.

실제 연결 여부는 본인의 키·프로젝트·모델을 입력한 뒤 화면의 연결 테스트로 확인하세요.
