# 재료 아이콘

내장 image_gen 도구로 제작한 2D 애니메이션풍 게임용 아이콘 23종입니다. 또렷한 외곽선과 단순한 명암으로 형태를 구분하며, 사실적인 표면 질감과 반사광을 줄였습니다.

- 경험치: 성장의 조각, 성장의 결정, 성장의 정수
- 스킬 강화: 속성별 각인석 9종, 공용 각인석
- 캐릭터 돌파: 속성별 촉매 9종, 공용 촉매

모든 이미지의 크기는 1254 × 1254px이며 1:1 비율의 투명 배경 PNG입니다. 개별 아이콘에 이름이나 수량은 포함하지 않았습니다.

`index.html`을 열면 이름별 전체 미리보기를 확인할 수 있습니다. 표시 크기와 배경을 바꿔 확인하고 아이콘을 눌러 확대할 수 있습니다.

`manifest.json`에는 파일명과 이름, 분류가 있으며 `generation-prompts.json`에는 내장 image_gen 도구에 전달한 최종 생성 프롬프트가 있습니다.
