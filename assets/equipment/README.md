# 장비 아이콘과 세트 기획

내장 image_gen으로 제작한 2D 애니메이션풍 장비 아이콘 60종입니다. 클래스 전용 8세트와 공용 2세트이며, 각 세트는 무기·갑옷·장갑·신발·반지·목걸이 6부위입니다. 모든 원본은 1254 × 1254 투명 PNG입니다.

`index.html`은 세트/부위 필터, 크기 조절, 투명 배경 확인, 확대 보기와 세트 효과를 제공하는 미리보기입니다.

`manifest.json`은 세트별 착용 클래스, 2/4세트 능력치, 4세트 특수 효과 및 아이콘 경로를 보관합니다. 숫자는 현재 밸런스 초안입니다. `generation-prompts.json`에는 실제 프롬프트와 참조 이미지 역할을 기록했습니다.

이 폴더는 아트와 기획 자료입니다. 기존 게임의 미리보기 장비 인벤토리와 전투 효과 실행에는 아직 연결하지 않았습니다. 서로 강도와 지속시간이 다른 동일 상태 효과의 처리 방식도 미확정으로 명시했습니다.
