# 장비 아이콘과 세트 기획

내장 image_gen으로 제작한 2D 애니메이션풍 장비 아이콘 60종입니다. 클래스 전용 8세트와 공용 2세트이며, 각 세트는 무기·갑옷·장갑·신발·반지·목걸이 6부위입니다. 모든 원본은 1254 × 1254 투명 PNG입니다.

`index.html`은 세트/부위 필터, 크기 조절, 투명 배경 확인, 확대 보기와 세트 효과를 제공하는 미리보기입니다.

`manifest.json`은 세트별 착용 클래스, 2/4세트 능력치, 4세트 특수 효과 및 아이콘 경로를 보관합니다. 숫자는 현재 밸런스 초안입니다. `generation-prompts.json`에는 실제 프롬프트와 참조 이미지 역할을 기록했습니다.

게임 인벤토리·장착 목록·착용 슬롯·옵션 정보·강화 화면·소환 출현 목록에 아이콘 60종을 연결했습니다. 기존 예시 장비를 대체하는 공유 미리보기 인벤토리이며, 장비 인스턴스 하나는 한 캐릭터만 착용할 수 있습니다. 전용 장비는 해당 클래스만 착용하며 공용 장비는 모두 착용합니다. 게임 저장 및 실제 획득 경로는 별도 연결 예정입니다.

2/4세트 능력치는 캐릭터 스탯에 반영됩니다. 비율 보너스는 기본 캐릭터 스탯 기준으로 합산한 뒤 한 번 반올림하며, 장비 주/부 옵션은 별도로 더합니다. 치명타 확률·피해 및 효과 적중·저항은 퍼센트포인트를 더합니다. 6개를 착용해도 2/4세트 효과가 중복 적용되지 않습니다.

4세트 특수 효과는 정보 화면과 활성 세트 효과에 표시하며 `getCharacterEquipmentSpecialEffects`로 전투에 전달할 수 있습니다. 현재 전투는 화면 미리보기이므로 실제 공격·도발·보호막 등의 실행은 아직 없습니다. 향후 스킬과 장비 효과를 독립 판정하며 동일 상태의 지속시간은 합산하지 않고 긴 쪽을 적용합니다. 서로 강도와 지속시간이 다른 동일 상태 효과의 처리 방식은 미확정으로 명시했습니다.
